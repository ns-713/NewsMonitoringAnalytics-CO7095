Figure 3: UML Sequence Diagram: RSS Ingestion & Alerting Pipeline (Section A4)

sequenceDiagram
    autonumber
    actor User as User / CLI Menu
    participant Menu as menu.py
    participant RSS as RssService
    participant Dup as DuplicateService
    participant Srv as Categorisation & Sentiment
    participant Store as JsonStorage
    participant Alert as AlertService

    User->>Menu: Select [4] Ingest RSS Feeds
    Menu->>RSS: fetch_and_parse_feed(feed_url)
    RSS->>RSS: ElementTree parse with fault isolation
    loop For Each Parsed Item in Feed
        RSS->>Dup: is_duplicate(item, existing_articles)
        alt Duplicate Detected (URL, Headline, Jaccard >= 0.70)
            Dup-->>RSS: True (Item Skipped)
        else Novel Unique Item
            Dup-->>RSS: False
            RSS->>Srv: predict_category() & score_sentiment()
            Srv-->>RSS: Enriched Article Object
            RSS->>Store: save_article(article)
            Store->>Store: Atomic swap (.tmp -> os.replace)
            RSS->>Alert: evaluate_article_against_rules(article)
            opt Keyword Matches Active Rule
                Alert->>Store: save_alert(UNREAD)
            end
        end
    end
    RSS-->>Menu: Ingestion Summary (Added / Skipped)
    Menu-->>User: Display Ingestion Results
