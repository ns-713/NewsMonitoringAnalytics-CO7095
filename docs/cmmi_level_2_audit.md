## 1. Audit Framework and Academic Disclaimer

> [!CAUTION]
> **Audit Context and Certification Disclaimer:**
> In accordance with assignment instructions and academic integrity standards, this document represents an **internal academic process audit against CMMI Level 2 process expectations**.
> **The project does NOT claim official CMMI certification**, nor does it claim that the development organization has reached formal CMMI Level 2 appraisal status. This artifact evaluates coursework development processes against recognized Software Engineering Institute (SEI) Maturity Level 2 (Managed) process areas.

CMMI Level 2 ("Managed") establishes that projects are planned, performed, measured, and controlled according to documented standards. The audit examines the **seven core Level 2 process areas**:
1. **Requirements Management (REQM)**
2. **Project Planning (PP)**
3. **Project Monitoring and Control (PMC)**
4. **Supplier Agreement Management (SAM)**
5. **Measurement and Analysis (MA)**
6. **Process and Product Quality Assurance (PPQA)**
7. **Configuration Management (CM)**

## 3. Audit Summary, Gap Analysis, and Continuous Improvement

### 3.1 Strengths Identified
1. **Exceptional Automated Test Rigor**: 139 discrete automated tests combining black-box, white-box, concolic, and symbolic execution techniques with 100% pass rate.
2. **Robust Configuration Management**: Atomic file writing and automated `.bak` generation protect runtime data from unhandled corruption.
3. **Comprehensive Measurement Infrastructure**: Native standard-library coverage tracing ensures full software measurement compliance on lab hardware.

### 3.2 Process Gaps and Recommendations
- **Gap 1**: Absence of mandatory branch protection rules enforced by GitHub remote settings (relies on team discipline).
  - *Recommendation*: Configure GitHub repository settings to require at least 1 approving pull request review before merging into `develop`.
- **Gap 2**: EVM tracking recorded at sprint boundaries rather than daily continuous intervals.
  - *Recommendation*: Update daily burndown sheets with logged labor hours during the daily standup.
